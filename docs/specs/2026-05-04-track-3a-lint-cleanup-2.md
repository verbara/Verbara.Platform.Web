# Spec: Track 3A — lint-cleanup-2

**Created:** 2026-05-04
**Track:** Nivel 3 — Code Quality
**Version target:** `1.16.0`

## Problem

131 ESLint problems (116 errors + 15 warnings) accumulated during rapid feature delivery in v1.13.x–v1.15.x. The lint job runs non-blocking (`continue-on-error: true`) in CI, providing no enforcement value. This track eliminates all problems and makes lint a hard gate.

## Design

### A. react-refresh/only-export-components (92 → 0)

#### A1. `router.tsx` — 85 errors

**Fix:** Add eslint config override disabling the rule for this file.

**Rationale:** `router.tsx` is routing infrastructure (85 `lazy()` const declarations + `createBrowserRouter()` config). It is not a React component and never participates as an HMR refresh boundary. The rule is semantically irrelevant here.

#### A2. UI component dead exports — 3 errors

Files: `src/core/ui/badge.tsx`, `src/core/ui/button.tsx`, `src/core/ui/tabs.tsx`

Each exports a `cva` variant object (`badgeVariants`, `buttonVariants`, `tabsListVariants`) that has **zero external consumers** (verified via project-wide grep). These are generated by shadcn/ui scaffolding but unused.

**Fix:** Remove from the `export` statement. The variant object stays in the file (co-location is correct — it's intrinsically coupled to the component). If a consumer needs programmatic access to variants later, re-exporting is trivial.

#### A3. `channel-config-form.tsx` — 3 errors

Exports: `channelFields` (config constant), `buildSchema` (utility fn), `buildDefaults` (utility fn).

All three are consumed by `src/admin/setup/steps/channel-step.tsx`. This is shared domain logic that leaked into a component file.

**Fix:** Extract to `src/admin/channels/channel-fields.ts`:

- Move `FieldDef` interface, `channelFields` constant, `buildSchema`, `buildDefaults`
- Update imports in `channel-config-form.tsx` and `channel-step.tsx`

#### A4. `license-page.tsx` — 1 error

Export: `parseGraceDuration` — comment says "Exported for StatCard test harness" but no test or file imports it. Stale.

**Fix:** Remove `export` keyword. Function becomes module-private.

### B. @typescript-eslint/no-explicit-any (17 → 0)

#### B1. zodResolver casts — 13 instances

Pattern: `useForm<FormValues>({ resolver: zodResolver(schema) as any })`

In every case, `FormValues = z.infer<typeof schema>`. The types already match — the `as any` was added defensively when the hookform/resolvers package had a type mismatch that has since been fixed.

**Fix:** Remove `as any`. Either:

- Drop the explicit generic: `useForm({ resolver: zodResolver(schema) })` (TS infers)
- Or keep the generic without cast: `useForm<FormValues>({ resolver: zodResolver(schema) })` (works with current @hookform/resolvers 4.x)

If any instance fails type-check without the cast, use `as Resolver<FormValues>` (explicit narrow cast, not `any`).

Files (13): `quotas-page.tsx`, `rate-card-form.tsx`, `bot-form.tsx`, `cluster-page.tsx` (×3), `retention-policy-section.tsx`, `profile-form.tsx`, `report-form.tsx`, `route-form.tsx`, `survey-form.tsx`, `tenants-page.tsx`, `trunk-form.tsx`

#### B2. RHF prop interface types — 4 instances (1 file)

File: `src/admin/gdpr/retention-policy-section.tsx`

```ts
interface RetentionFieldRowProps {
  control: any; // → Control<RetentionFormValues>
  watch: any; // → UseFormWatch<RetentionFormValues>
  setValue: any; // → UseFormSetValue<RetentionFormValues>
}
```

**Fix:** Import and use typed RHF generics: `Control<T>`, `UseFormWatch<T>`, `UseFormSetValue<T>`.

### C. React Compiler Errors (7 → 0)

#### C1. setState-in-effect — 5 instances

| File                           | Line(s)  | Pattern                                                                 | Fix                                                                                    |
| ------------------------------ | -------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `agent-assist-config-page.tsx` | 166, 497 | `useEffect(() => setLocalRules(rules), [rules])`                        | Initialize state from `rules`; use component `key` to reset on identity change         |
| `queue-form.tsx`               | 103      | `useEffect(() => { reset(defaults); setSkillInput('') }, [open])`       | Move to dialog `onOpenChange` handler (event-driven, not effect-driven)                |
| `reply-composer.tsx`           | 47       | `useEffect(() => { setText(draft); ... }, [conversationId])`            | Add `key={conversationId}` on component to force remount and clean state               |
| `kiosk-wrapper.tsx`            | 46       | `useEffect(() => setIsKiosk(params.get('kiosk') === 'true'), [params])` | Remove `isKiosk` state; derive: `const isKiosk = searchParams.get('kiosk') === 'true'` |

#### C2. purity — 1 instance

File: `src/admin/system/auth-sessions-page.tsx:30`

`timeAgo()` calls `Date.now()` during render. Non-deterministic.

**Fix:** Move `timeAgo` outside component body. Compute formatted strings via `useMemo` with `sessions` as dependency and a stable `now` value captured once per render cycle via `Date.now()` inside the memo (pure relative to React's model since it runs once per sessions update).

#### C3. immutability (self-referencing useCallback) — 1 instance

File: `src/core/hooks/use-sse.ts:215,220`

`connect` function inside `useCallback` references itself for reconnection via `setTimeout(connect, delay)`. The Compiler cannot prove immutability of the closure.

**Fix:** Use ref-based self-reference pattern:

```ts
const connectRef = useRef<() => void>(null);
const connect = useCallback(() => {
  // ... SSE setup ...
  source.onerror = () => {
    setTimeout(() => connectRef.current?.(), delay);
  };
}, [deps]);
connectRef.current = connect;
```

### D. Warnings (15 → 0)

#### D1. coverage/ directory linted — 6 warnings

`coverage/` is in `.gitignore` but not in eslint's `globalIgnores`. Generated report files trigger "unused eslint-disable" warnings.

**Fix:** Add `'coverage'` to `globalIgnores(['dist', 'coverage'])`.

#### D2. Stale eslint-disable directive — 1 warning

File: `src/admin/cases/cases-page.tsx:132` — `/* eslint-disable react-hooks/preserve-manual-memoization */` no longer needed.

**Fix:** Remove the directive.

#### D3. react-hooks/incompatible-library — 8 warnings

React Hook Form's `watch()` and TanStack Table's `useReactTable()` use subscription models incompatible with the React Compiler. This is an ecosystem gap — libraries need updates.

| Strategy                              | Files                                                                                      | Reason                                                                             |
| ------------------------------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| Migrate `watch()` → `useWatch()` hook | `channel-config-form`, `dialer-settings-page`, `report-form`, `survey-form`, `system-page` | `useWatch` is a proper React hook; Compiler-friendly for inline render usage       |
| File-level suppress                   | `property-panel.tsx`, `channel-step.tsx`                                                   | Uses `watch((cb) => ...).unsubscribe()` subscription pattern — no hook alternative |
| File-level suppress                   | `data-table.tsx`                                                                           | TanStack Table internal subscriptions, no code-level fix available                 |

Suppress format: `/* eslint-disable react-hooks/incompatible-library */` at file top with one-line justification comment.
